# A股多因子量化回测系统执行合同与规范 (Execution Contract)

## 1. 用途与适用范围
本文件规定 A股多因子量化回测系统（A-Share Backtest Engine）的执行口径、交易逻辑与评价标准。本系统旨在评估不同机器学习模型、特征子集（消融实验）以及主题股票池约束下的策略表现。

**适用策略与实验组：**
| 实验组 | 候选池 | 目标持仓数 (Top K) | 排除北交所 (`.BJ`/`_BJ`) | 核心逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| **Full-Market** | 全市场有效标的 (`BUY_MASK=1`) | 25 | 是 | 全截面多因子打分排序 |
| **Tech-25 (Pool)** | 当月生效的 `trade_pool_YYYYMM.csv` | 25 | 是 | 主题股票池硬约束 + 模型打分 |
| **Ablation** | 全市场有效标的 | 25 | 是 | 使用 SHAP 筛选的 Top 因子子集 |
| **DynamicSwitch** | 全市场有效标的 | 25 | 是 | 基于 Rank IC 的动态模型路由 |

**模型输入要求：**
*   每行唯一键为 `S_INFO_WINDCODE + TRADE_DT`。
*   特征必须经过严格的截面标准化（`_MKT_Z` 全市场标准化，`_IND_Z` 行业标准化）。
*   严格遵循物理级数据隔离：训练集 (`DATA_SOURCE='train'`) 与测试集 (`DATA_SOURCE='test'`) 绝对隔离，2025-01-01 之后模型永久冻结，杜绝任何样本外数据泄漏。

## 2. 特征工程与模型体系
### 2.1 特征体系
*   **基础因子**：包含 450+ 个财务基本面、量价技术因子及市场宽度指标（`Breadth_global`, `Breadth_industry`）。
*   **衍生因子**：动态计算过去 10/20/30 天的平均收益率 (`RET_MEAN_*_MKT_Z`) 与夏普比率 (`SHARPE_*_MKT_Z`)。
*   **掩码过滤**：严格依赖 `FEATURE_MASK=1` 过滤无效样本，依赖 `BUY_MASK=1` 过滤不可交易标的。

### 2.2 模型矩阵
系统采用预训练模型加载机制，支持以下模型矩阵：
| 模型类别 | 模型名称 | 训练集窗口 | 验证集窗口 | 特征集 |
| :--- | :--- | :--- | :--- | :--- |
| 线性模型 | `ElasticNet` | 2015-06 至 2024-08 | 无 | 全量 / 消融子集 |
| XGBoost | `XGB-22` / `XGB-23` / `XGB-24` | 分别截止至 2022 / 2023 / 2024-08 | 22/23 包含验证集早停 | `FEATURE_SELECTED_XGB` |
| LightGBM | `LGBM-22` / `LGBM-23` / `LGBM-24` | 分别截止至 2022 / 2023 / 2024-08 | 22/23 包含验证集早停 | `FEATURE_SELECTED_LGBM` |
| 启发式 | `OptSharpe` | N/A (基于历史 30 日收益协方差) | N/A | N/A |

## 3. 回测时间与调仓框架
| 项目 | 固定口径 |
| :--- | :--- |
| **交易日历** | A股标准交易日历（自动处理节假日顺延） |
| **调仓频率** | **按周调仓**：默认每周五 (`REBALANCE_WEEKDAY = 4`)。若周五非交易日，则自动顺延至该周第一个 >= 周五的交易日。 |
| **执行滞后** | `execution_lag_days = 0`（当日收盘信号，当日收盘成交假设） |
| **排序时点** | 调仓日当日横截面 |
| **成交价** | `S_DQ_ADJCLOSE` (后复权收盘价，用于估值与成本计算) |
| **模型冻结** | 2025-01-01 起，模型参数永久锁定，仅执行 `predict`。 |

## 4. 调仓与资金机制 (增量调仓逻辑)
本系统**摒弃**了传统的全量权重再平衡，采用**最小化换手的增量调仓机制**，以真实反映 A 股交易摩擦。

### 4.1 初始建仓
*   **初始资金**：10,000,000 元。
*   **BuyAndHoldAll 基线**：首个交易日全量等权买入所有 `BUY_MASK=1` 标的，后续永不换仓。
*   **ML 策略建仓**：首个调仓日，按模型预测分数排序选取 Top 25，可用现金在 Top 25 间尽量等额分配。

### 4.2 后续增量调仓 (核心逻辑)
调仓日按下列集合运算顺序执行：
1.  **卖出集合 (Sell Set)** = `当前持仓 - 新 Top 25`。
    *   全部清仓，释放现金。扣除单边佣金。
    *   **胜率统计**：对比卖出价与该股票的**加权平均持仓成本**，若盈利则 `wins + 1`，否则 `losses + 1`。
2.  **保留集合 (Hold Set)** = `当前持仓 ∩ 新 Top 25`。
    *   **零摩擦持有**：不产生任何买卖指令，权重随市场自然漂移。
3.  **买入集合 (Buy Set)** = `新 Top 25 - 当前持仓`。
    *   将**卖出释放的现金 + 原有闲置现金**汇总，在买入集合内**等权分配**。
    *   按 `S_DQ_ADJCLOSE` 向下取整至 100 股（A股整手规则）。
    *   扣除单边佣金。若现金不足以买入 1 手，则跳过该标的。

## 5. 成本、交易约束与不可成交处理
### 5.1 交易成本
| 项目 | 当前值 |
| :--- | :--- |
| **单边佣金** | 2 bps (`COMMISSION_RATE = 0.0002`) |
| **印花税/滑点** | 0 bps (当前配置未计入，预留接口) |
| **买入成本** | `成交股数 * 价格 * (1 + 0.0002)` |
| **卖出到账** | `成交股数 * 价格 * (1 - 0.0002)` |

### 5.2 买卖约束条件
*   **买入条件**：`FEATURE_MASK = 1` 且 `BUY_MASK = 1` 且 价格有效 (`> 1e-6`)。
*   **卖出条件**：标的跌出 Top 25 且 价格有效。
*   **股票池硬约束 (Tech-25)**：若启用 `trade_pool`，则 `Buy Set` 必须严格属于当月 `effective_month` 对应的 `code` 集合。若模型选出的 Top 25 中有不在池内的标的，直接过滤剔除，可能导致实际持仓 < 25。

## 6. 实验路由与动态切换
### 6.1 DynamicSwitch (动态模型路由)
*   **状态记录**：每日计算各基础模型（`ElasticNet`, `OptSharpe`, `XGB-*`, `LGBM-*`）在当日截面的 Rank IC。
*   **切换触发**：仅在**调仓日**评估。计算各模型过去 10 个交易日的平均 Rank IC。
*   **切换条件**：若 `Best_Model_IC > B * Current_Model_IC` (默认 `B = 1.00`)，则将 `DynamicSwitch` 策略的底层打分模型切换为 `Best_Model`。
*   **防抖机制**：当前模型历史 IC 记录不足 10 天时，不触发切换。

### 6.2 无未来函数误差结算 (Delayed Realized Error)
*   **T 日 (预测日)**：模型生成预测分数，**仅缓存**，绝不访问 `label_i`。
*   **T+i 日 (结算日)**：真实收益已客观实现。系统回溯读取 T 日的缓存预测值，与 T 日数据中已实现的 `label_i` 计算 MSE/MAE。
*   **记录归属**：误差记录在 **T+i 日**的时间序列上，真实反映“事后验尸”的客观规律。

## 7. 结果评价与交付要求
### 7.1 核心评价指标
| 指标 | 定义 / 计算口径 |
| :--- | :--- |
| **Total PnL** | 测试期累计收益率 (期末 NAV / 期初 NAV - 1) |
| **Annual Ret** | 年化收益率 `((1 + CumRet) ^ (252 / Days) - 1)` |
| **Max DD** | 测试期历史最大回撤 |
| **Sharpe** | 年化夏普比率 `AnnualRet / (Volatility + 1e-8)` |
| **Win Rate** | **单笔平仓胜率** (`wins / total_closed_trades`) |
| **Closed Trades** | 测试期内完成的平仓交易总笔数 |

### 7.2 交付物清单
每个实验组必须输出以下文件至 `output/` 目录：
1.  **绩效图表**：`pnl_combined.png` (归一化净值), `drawdown_combined.png` (回撤), `rolling_sharpe_combined.png` (30日滚动夏普)。
2.  **诊断图表**：`daily_rank_ic_trend.png` (含 DynamicSwitch 阶梯图), `realized_prediction_error_mse.png` (无未来函数 MSE 时序)。
3.  **可解释性**：`shap_summary_*.png` (蜂群图), `shap_importance_*.json`。
4.  **审计日志**：`log/trades_{MODEL}.csv` (完整买卖明细), `output/backtest_summary.json` (结构化绩效汇总)。

## 8. 验收清单 (Checklist)
- [ ] 数据隔离：确认 `DATA_SOURCE='train'` 过滤生效，2025-01-01 后无模型重训日志。
- [ ] 增量调仓：检查 `log/trades_*.csv`，确认留在 Top 25 内的标的未产生重复买卖记录。
- [ ] 股票池约束：确认 Tech-25 实验的持仓标的 100% 属于当月 `trade_pool` 名单。
- [ ] 成本扣除：确认买卖操作均按 2bps 扣除了佣金，且现金余额计算无误。
- [ ] 胜率统计：确认 `backtest_summary.json` 中的 `win_rate_pct` 基于真实的平仓成本对比。
- [ ] 误差结算：确认 MSE 曲线的首个数据点出现在 `T + REBALANCE_DAYS` 之后。
- [ ] 节假日顺延：确认按周调仓逻辑在遇到长假时，正确顺延至节后首个交易日。
