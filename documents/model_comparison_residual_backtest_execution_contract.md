# 模型横向比较合同：Residual、回测与交易执行

## 1. 用途与适用范围

本文件规定不同模型的横向比较口径。比较新模型时，仅替换每日股票预测分数；候选池、Residual 处理、调仓、资金、成交限制、成本、样本区间和评价指标必须固定。

适用策略：

| 策略 | 候选池 | 股票数 | 排除 BJ |
|---|---|---:|:---:|
| RIVA-CN | 创业板 `3*` 与科创板 `688*` | Top25 | 是 |
| RIVA-CN/Tech-25 | 当月生效的 Wind 审核 `trade_pool_YYYYMM.csv` | Top25 | 是 |

新模型输入要求：

1. 每行唯一键为 `S_INFO_WINDCODE + TRADE_DT`。
2. 提供方向一致的原始预测分数 `PRED_Z_RAW`，分数越大代表预期收益越高。
3. 使用同一测试样本、同一可用交易日、同一候选池有效日期和同一 `BUY_MASK`/`FEATURE_MASK`。
4. 若模型产生多个分数头，必须在回测前固定唯一的主分数，禁止按回测表现临时选择分数头。

## 2. Residual 分数处理

### 2.1 处理顺序

每个交易日独立执行以下步骤：

1. 读取模型原始分数 `PRED_Z_RAW`。
2. 先应用策略候选池过滤。
3. 在过滤后的当日横截面计算风格暴露。
4. 以 `PRED_Z_RAW` 对风格变量和申万一级行业哑变量做无权最小二乘回归（OLS）。
5. 回归残差记为 `RESID_SCORE`，分数越大，表示在控制当日风格与行业后模型给出的相对高分越强。

Residual 只用于排序和路由比较，不改写模型原始输出文件。

### 2.2 回归形式

对股票 `i`、交易日 `t`：

```text
PRED_Z_RAW(i,t)
  = alpha(t)
  + beta_size(t) * z(log_mcap)
  + beta_turnover(t) * z(turnover_proxy)
  + beta_vol20(t) * z(vol20)
  + beta_vol60(t) * z(vol60)
  + beta_mom20(t) * z(mom20)
  + beta_mom60(t) * z(mom60)
  + SW_L1 industry dummies
  + residual(i,t)

RESID_SCORE(i,t) = residual(i,t)
```

连续风格变量在当日有效横截面中以总体标准差 `ddof=0` 做 z-score；行业使用 `SW_L1_NAME`，缺失时回退 `SW_L1_CODE`，再缺失标记为 `missing`；行业哑变量保留截距并去掉一个基准行业。

### 2.3 风格变量定义

| 变量 | 当前代码定义 |
|---|---|
| `log_mcap` | `log1p(S_DQ_CLOSE * S_DQ_CAPITAL / 10000)` |
| `turnover_proxy` | `S_DQ_VOLUME / S_DQ_CAPITAL` |
| `vol20` | `S_DQ_ADJCLOSE` 日收益率的 20 日标准差，最少 10 个观察值 |
| `vol60` | `S_DQ_ADJCLOSE` 日收益率的 60 日标准差，最少 20 个观察值 |
| `mom20` | `S_DQ_ADJCLOSE` 的 20 日涨跌幅 |
| `mom60` | `S_DQ_ADJCLOSE` 的 60 日涨跌幅 |

### 2.4 有效性与缺失处理

1. `PRED_Z_RAW`、六个风格变量和行业必须有效；不满足时该股票当日 `RESID_SCORE` 为空。
2. 当日有效样本少于 `100` 只股票时不回归。
3. 若回归设计矩阵列数达到样本数减 `5`，该日不回归，避免过度参数化。
4. 当前实现不做 winsorize、分位数截断、加权回归、鲁棒回归或截面行业中性配额。
5. Top25 排序前，残差缺失值降为极低分 `-1e6`；在候选池有效分数充足时，它们不会进入目标持仓。

### 2.5 模型比较要求

- 每个模型均在同一候选池内重新计算 Residual；禁止复用另一模型的残差。
- 若比较 `raw`，直接以各模型的 `PRED_Z_RAW` 降序排序。
- 若比较 `residual`，直接以各模型当日重算的 `RESID_SCORE` 降序排序。
- 若使用 `sensitive_switch` 或 Rank IC 路由，路由窗口、成熟标签规则、确认天数和状态机必须在各模型间固定。

## 3. 回测时间与调仓框架

| 项目 | 固定口径 |
|---|---|
| 交易日历 | 执行市场面板中的可用交易日历 |
| 调仓频率 | 全局每 5 个交易日一次 |
| 执行滞后 | `execution_lag_days = 0` |
| 排序时点 | 调仓日当日横截面 |
| 成交价 | `S_DQ_CLOSE` |
| 持仓估值 | `S_DQ_ADJCLOSE` 日度复权更新 |
| 期末处理 | 现金加未平仓持仓市值；不强制平仓 |
| 尾段开仓 | `stop_new_buy_last_n_days = 0`，最后 5 个交易日照常开新仓 |

当前历史框架采用“当日收盘信号、当日收盘成交”的零滞后假设。该假设适合对比不同模型的相对选股能力；若评估绝对可交易收益，应另行重放 `14:53` QMT 截面、收盘前 VWAP 或下一交易日开盘成交。

五相位回测时，每个起始相位独立以相同初始资金启动，不在相位之间传递资金、仓位或路由状态。

## 4. 调仓与资金机制

### 4.1 初始建仓

| 项目 | 固定口径 |
|---|---|
| 初始资金 | `10,000,000` 元 |
| 目标组合 | 当日可交易 Top25 |
| 下单单位 | 100 股整手 |
| 首次分配 | 可用现金在当日可买入的新股票间尽量等额分配 |
| 剩余现金 | 因整手、价格或不可买入标的产生，保留为现金 |

### 4.2 后续调仓

调仓日按下列顺序执行：

1. 用当日 `S_DQ_ADJCLOSE` 更新全部既有持仓的复权市值。
2. 生成当日 Top25 目标名单。
3. 已到五日复核期且仍在目标名单中的股票续持，并将下一复核日顺延 5 个交易日。
4. 已到复核期且不在目标名单中的股票，在可卖时卖出；卖出所得回到现金。
5. 已持仓且仍在目标名单中的股票不卖出重买，也不补充资金加仓。
6. 对空出的持仓槽位买入未持有的目标股票；当日可用现金只在这些可买入新股票之间尽量等额分配。

因此，组合采用“持仓随收益漂移、到期卖旧买新”的机制，不执行每 5 日将全部持仓强制调回等权的再平衡。

## 5. 成本、交易约束与不可成交处理

### 5.1 成本

| 项目 | 当前值 |
|---|---:|
| 单边佣金 | 2bps |
| 单边额外滑点 | 0bps |
| 买入成本率 | `0.0002` |
| 卖出成本率 | `0.0002` |
| 印花税、冲击成本、容量成本 | 当前未计入 |

买入现金需求为 `成交股数 * S_DQ_CLOSE * (1 + 0.0002)`；卖出到账现金为 `持仓复权市值 * (1 - 0.0002)`。

### 5.2 买入条件

买入标的必须同时满足：

1. `FEATURE_MASK = 1`。
2. `BUY_MASK = 1`。
3. 交易状态有效，收盘价、复权收盘价、成交量、成交额、涨停价和跌停价均有效。
4. 成交量大于 `0`，成交额大于 `0`。
5. 非涨停；涨停判断使用 `S_DQ_CLOSE >= S_DQ_LIMIT - 0.01`。
6. 现金足以买入至少一手。

### 5.3 卖出条件

卖出标的必须交易有效且非跌停；跌停判断使用 `S_DQ_CLOSE <= S_DQ_STOPPING + 0.01`。当前执行引擎的卖出门槛来自原始市场交易状态与跌停状态，`SELL_MASK` 仅写入审计留痕，不作为卖出拦截条件。

### 5.4 不可成交

| 情形 | 处理 |
|---|---|
| 涨停、停牌、无有效成交 | 不买入，保留现金或使用其他可买入目标股 |
| 跌停、停牌、无有效成交 | 不卖出，保留原持仓，后续交易日继续尝试 |
| 整手与现金不足 | 跳过该股票或按可承受整手下单 |
| 期末仍有持仓 | 按当日复权市值计入 NAV，不产生额外卖出成本 |

## 6. 路由口径

若使用路由，以下条件必须在模型间固定：

| 路由 | 定义 |
|---|---|
| 原始 `sensitive_switch` | Raw 进入需同时满足 Raw Rank IC 优于 Residual、Raw Top-Bottom Spread 优于 Residual、Raw Spread 胜率至少 60%、Raw Top25 不拥挤，并连续 5 个交易日成立；Raw 平均 Rank IC 或平均 Top-Bottom Spread 小于等于 0 时立即切回 Residual |
| Rank IC 路由 | 最近 10 个成熟信号日的 Raw 与 Residual 平均 Rank IC 严格比较；Residual 状态下 Raw 更高则切 Raw，Raw 状态下 Raw 更低则切 Residual，相等时保持原状态 |

路由每日更新；实际交易仍只发生在固定五日调仓日。不同模型的比较应使用相同路由版本，不能用不同路由为某一模型择优。

## 7. 结果评价与交付要求

每个模型至少输出：

1. 每相位 NAV 曲线、总收益、最大回撤、年化收益、年化波动率、Sharpe-like、日胜率和换手率。
2. 每日 Top25、每日持仓、成交记录、未平仓持仓和不可成交统计。
3. Raw、Residual 和路由决策的每日分数及状态留痕。
4. 同一相位集合下的模型对比表，报告均值、中位数、每相位差值和最差相位。

模型优劣判断以相同合同下的多相位结果为准；单一相位收益、单一阶段市场风格或只挑选最优路由的结果不能作为模型胜出的依据。

## 8. 验收清单

- [ ] 模型预测日期和股票键无重复。
- [ ] 候选池、月度 `effective_month`、BJ 过滤与原比较组一致。
- [ ] Residual 六个风格变量、行业定义和 OLS 条件未变。
- [ ] TopN、五日调仓、零滞后、初始资金、整手、佣金和滑点未变。
- [ ] `stop_new_buy_last_n_days = 0`。
- [ ] 同日收盘成交假设已在报告中明确。
- [ ] 输出含完整 NAV、持仓、成交、路由和不可成交审计文件。
